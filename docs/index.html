What is inside

Three add-ins, one job: less reading.

Each one lives next to the message you have open and only touches that message or its thread.

Gmail · Email Buddy

Summarise the whole thread, not just the last email

Email Buddy is a Gmail add-on written in Apps Script. It reads up to the last 25 messages of a conversation and returns the topic, decisions, dates and open actions.

  • Summarise one email or the full conversation
  • Draft a reply you can edit, save as a draft or send
  • Your OpenAI key lives in script properties, never in code
Gmail · Email Buddy

Ask the thread a question

Start a chat and the add-in loads the thread as context. Ask what it costs, when it ships or what is still blocking it, and the answer quotes the thread back to you.

Outlook · AI assistant

A two-pass summary, then a ready reply

The Office.js task pane first pulls out key points, then writes a short summary from them. One click turns it into a reply and opens Outlook's own reply-all form with the draft inside.

  • Built on Microsoft's Office add-in TaskPane template
  • Key stored in Outlook roaming settings, per user
  • Nothing is sent without you pressing Send
Outlook · Next.js summarizer

Plus the first prototype, kept honest

The Next.js summarizer is where it started: a task pane that picks the first sentences of the email, with no AI call at all. It is a small, readable starting point if you want to build your own Outlook add-in in React.

How it works

One email in, one useful answer out

There is no server of ours in the middle. The add-in reads the message through the host's add-in API and calls OpenAI with your key.

gmail-email-buddy/

Email Buddy

Apps Script Gmail add-on. GetContextualAddOn.gs plus the appsscript.json manifest. Uses gpt-4o-mini.

outlook-ai-assistant/

Outlook AI assistant

TypeScript + webpack task pane from the Office template. Summary, reply and settings views. Uses gpt-3.5-turbo.

outlook-summarizer/

Outlook summarizer

Next.js 13 task pane prototype with an HTTPS dev server. Extractive summary, no AI call.

Quick start

See it in two minutes, no keys needed

The preview runs all three add-ins in a local mock mail window with invented emails and a stand-in model.

Local preview

# build the two Outlook add-ins
cd outlook-ai-assistant && npm ci && npm run build
cd ../outlook-summarizer && npm install && npx next build
npx next start -H 127.0.0.1 -p 3102 &
# start the preview host
cd .. && node tools/preview/server.js
# open http://127.0.0.1:4310/?host=gmail

In a real mailbox

# Outlook: trusted localhost cert, then sideload
cd outlook-ai-assistant
npx office-addin-dev-certs install
npm run dev-server
# Outlook → Add-ins → My add-ins → Add from file
# → manifest.xml

# Gmail: paste the two files into an Apps Script
# project → Deploy → Test deployments → Gmail
